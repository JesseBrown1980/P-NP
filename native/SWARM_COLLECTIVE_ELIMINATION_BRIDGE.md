New native test-only module: [blind_cnf_factorization.rs](src/blind_cnf_factorization.rs). Input is DIMACS text alone (bounded test parser: 1–24 variables, one clause per line, distinct variables within clauses). Group clauses by support, recognize a 2- or 3-variable parity equation only if every falsifying assignment of that parity is excluded by an explicit clause. Remove exactly those clauses; keep others. Both parity encodings on one support imply contradiction. Row-reduce the equations over GF(2), prioritizing variables absent in residual clauses as pivots, substitute affine forms in the residual clauses, merge all free-coordinate supports touched by each clause. Count the Cartesian product of satisfying assignments by local enumeration. Equations give unique pivot values for free-variable assignments. This establishes correctness for the specified finite parser domain, without requiring a useful separator. It does not identify arbitrary implicit XOR relations. The reference DPLL counter performs its own clause restriction and unit propagation without parity extraction. No production solver or policy changes.
