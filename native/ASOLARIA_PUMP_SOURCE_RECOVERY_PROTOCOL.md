# Asolaria pump: source recovery and native whole-fabric acceptance

## Which historical pump is now implemented

The older Asolaria corpus contains multiple *different* pump constructs.
We must preserve all of them without silently mixing their algorithms.

**The first independently recoverable native source is the spherical Rime pump:**
JesseBrown1980/Asolaria at pinned commit
1c03dca255cd374ff7e6db19790c2317c1eb2c85,
docs/handoffs/acer-host8-rooms-guide-2026-10-19/host8rooms/src/tribit/mod.rs,
pinned original Git blob SHA 5d3e834e3073478bfb518f952c4c31fd1b9544c0.

The source defines an integer reversible 27-sample Rime prism (Law 20),
prime p=1,000,081, primitive 27th root w=951,846, generator g=7,
inverse using w^-1 and 27^-1, and the original logarithmic pump-shell
function that counts powers-of-three rungs. It also defines directional
zero-carrier semantics; these are not equated to physical quantum energy.

Two additional original lines are preserved as **separate source-parity
holds**, not treated as copies of the spherical pump:

- **Asolaria 27-node gradient pump:** the archived
  ASOLARIA-27-KERNEL-MATRIX-NETWORK-V1 experiment describes nine
  macro-kernels on a 3×3×3 Hamming graph (27 nodes, 81 edges);
  cyclic R0/R1/R2, OIL/ANTI_OIL/ANTI_ANTI_OIL,
  OPUS/FABLE/MYTHOS, a shared energy point, and deterministic
  gradient descent with fail-closed backtracking. Independent
  numerical gradient/energy-source code is required for a byte-exact
  Rust port and any claimed predictive effect.
- **ACER kernel-pump / MINS descriptor pump:** historical
  D:/asolaria-absorb/kernel-pump/pump_*.py is a local provenance
  source. MINS PUMP result = source X N generates a hash-plus-level
  descriptor, with function-of-functions 3→9→27 expansion,
  alternating pump/check, a fixed stopping rule and singleton
  scratch cleanup. The executable local script and original
  descriptor receipts must be source authenticated before calling
  a native replacement equivalent.

## Accepted executable first kernel

The new native asolaria_pump module carries the exact original
27-point modular spectrum and inverse, and its integer-only
logarithmic shell rule. For all original frozen 27-trit task vectors,
we compute three distinct cyclic label phases, with R^3(identity)
checked exactly. Each rotated phase is a NEW immutable child of the
original input state; the source is never overwritten. The declared
digital signal-energy proxy is the number of non-neutral trits
within that phase. This is a *newly specified software counter*,
not a claim to reproduce the 27-node gradient objective or
experimentally calibrated physical energy.

Actual data path:

    PRL original source and accepted temporal forecast
        → 54 original source-derived 27-trit tasks
        → four true binary floors: 64/256/1024/4096
        → all 40 original Omnibit reversible operators
        → original Fischer addressed native backend HTTP-0
        → independent binary-floor inverse and base-three decode
        → separate native 27-harmonic Rime prism for R0/R1/R2
        → 27-point inverse reconstruction / shell verification
        → immutable HBI/HBP/SHA/SH/HASH pump/refreeze receipt
        → original matrix/GNN evidence source roots and G4 HOLD

The producer uses the original iterative root multiplication
algorithm. The backend worker uses separately written W^(i*j)
powers as its independent 27-point reference and original inverse.
No neural checkpoint is claimed to run; trained GNN forward still
requires issue #49. A spectral refreeze is a reversible witness
and never modifies the already accepted causal probabilities.

54 authentic tasks × 4 binary floors × 40 original operators
= 8,640 exact pump messages for each of the 3/27/81 room-width
configurations, or **25,920 separate native HTTP-0 pump calls**.
Each call checks three 27-point spectra, three exact inverse
reconstructions, R3 winding and energy-shell values.
Original/frozen task source hashes and the original PRL
prediction archive are mandatory prerequisites.

## Fail-closed promotion requirements

- The original pinned p,g,w,k constants and exact prism inverse
  must agree with independently coded modular powers, with
  integral-only Rust1.81 execution and strict Clippy.
- Original shell examples 0→0, 1→1, 3→2, 9→3, 27→4
  are verified, and shell growth remains logarithmic.
- Every 54-task/4-floor/40-operator/3-capacity pump frame passes
  exact independent source reconstruction; no cache falsely
  substitutes a previously computed wave.
- Source/floor/operator corruption, wrong Fischer addresses and
  original task identity errors are rejected. All 27 harmonic
  field coordinates are in the accepted modular domain.
- The pump publishes 64 indexed HBI/HBP rows: source, five accepted
  predecessor roots, 54 immutable task/phase refreezes,
  three independent backend arm receipts and a summary.
- Refreeze, archive, original source and HBP index corruption are
  rejected, and all generated artifacts reproduce byte-identically.
  The second hosted job independently verifies published source
  and SHA-256 manifests. Protected upstream artifacts and prior
  automatic post-GULP scratch cleanup remain unchanged.
- No physical-energy or trained-GNN inference effects are
  inferred from exact spectral reconstruction alone.
