# Black–Brown–White behavioral-language discovery: independent oracle gate

## What is new since PR #68

PR #68 tested multiple reversible presentations of already supplied source/ciphertext pairs.
This gate supplies **new behavioral evidence**: directed action observations from an
opaque, initially unknown 27-symbol source language. The RNQ transformations are
distinct **representations of those observations**, and the Brown signed-difference
witness checks reconstruction. The extra source information is an observation from
the opaque system itself, charged equally to the direct and three-view solvers.

The unknown source labels are generated by three deterministic shuffled permutations
of all 27 symbols. The symbols are deliberately opaque and generally non-affine.
The learner gets only the public algebra of three commuting order-three actions,
one anchored starting label, and an explicitly limited number of observed edges.

All three hidden mappings are used only inside the source-fixture generator and
the post-prediction independent referee; no secret production key exists.
This is a **synthetic active-system identification experiment**. It does not
assert any solution for encryption that withholds behavioral observations.

## Observation schedule and combinatorial acceptance

The known abstract state graph is (Z/3Z)^3. There are 27 positions and three
labeled +1 coordinate actions per position = 81 possible directed transitions.
A source oracle independently supplies 26 edges of a breadth-first spanning
tree, but the learner is given only the first 23, then 24, then 25.

| Stage | Independent behavior edges | Discovered labels incl. origin | Missing label assignments | Valid unknown mappings |
|---|---:|---:|---:|---:|
| Initial | 23 | 24 | 3 | 3! = 6 |
| First new observation | 24 | 25 | 2 | 2! = 2 |
| Second new observation | 25 | 26 plus complement | 1 | 1! = 1 |

The complement is inferable because the *public* alphabet is known to contain
exactly the distinct labels 0..26. The program must account for this known
vocabulary in both arms.

Once the mapping is uniquely determined, the learner predicts all 81 opaque
transitions by the public abstract action laws. Of those, **56 transitions**
per fixture were never observed during fitting. An independent referee checks
every one against the source fixture, separately from the inference function.
Three distinct fixture permutations require **168/168** correct held-out edges.

### Matched baselines and the three-language cost

- The **direct baseline** infers from the same 25 observed source transitions
  and the same one anchored label.
- The **three-view/Brown arm** also receives exactly 25 transitions, displayed
  as original operator IDs 0, 2 and 7. Each is inverted and compared with its
  own source observation. The 75 per-fixture derived displays are evidence
  copies, not new source queries.
- Expected aggregate across three fixtures: 75 independent source transitions
  per arm; 150 direct observed endpoint symbols; 450 three-view displayed
  endpoint symbols; **zero additional independent source information** from
  the three derived views. Extra transforms and witness arithmetic are paid
  computation, so no runtime speedup is claimed.
- The Relic signed Brown witness checks all 27 canonical balanced-ternary
  triples per fixture, **81 reconstructions** in total, including a planted
  sum-zero witness that retains all signed components.
- A contradictory observed action, duplicated opaque label or altered
  held-out referee source must fail acceptance.

## Interpretation

The new source observations really reduce ambiguity from six possible maps to
two and then one. They are **not** calculated from the original observations
by changing alphabets. Both the direct and three-view methods benefit equally.

This is a valid, falsifiable example of learning a genuinely unknown symbol
assignment from behavioral observations under a **known commuting-order-three
rule structure**. It is a more meaningful communication test than purely
reversible encoding, while proving no additional entropy is created by the
Black–Brown–White copies.
