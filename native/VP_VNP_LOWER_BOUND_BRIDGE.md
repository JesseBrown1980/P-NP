## Connection to accepted finite slice research

P-NP PR #71 head d5386aee6d406e2bf2ffe04ff9d5b2cf1ab0e33c: mandatory native acceptance run 45519688416 reported success. See CONNECTED_SLICE_SEPARATOR.md and SWARM_COLLECTIVE_ELIMINATION_BRIDGE.md. Earlier QNN PRs #39–41 establish finite product and rank factorizations; their exact coordinate identities do not assert uniform algebraic circuit bounds.

Finite bound: for maximum input length N, the domain of binary strings of lengths 0..N has 2^(N+1)-1 elements; any decision function on it has a finite table. This does not yield a uniform polynomial bound when N varies.

Conditional arithmetic compilation lemma: suppose a family of symbolic weighted sums (with polynomially many factors, and a polynomially bounded number of finite-domain variables of size q) admits an exact symbolic tensor-network description whose entries have total polynomial arithmetic circuit size, and an elimination order whose largest bucket width is w. Each bucket multiplies the relevant table entries and sums over its variable. The output is represented by an arithmetic circuit using O((m+n)q^w) additional additions and multiplications, with initial entry circuits included separately. This follows because each factor is consumed once and each bucket has at most q^w entries. For bounded q and w=O(log N) this yields polynomial circuit size, provided the symbolic transformation and reconstruction costs are also polynomial and exact as polynomial identities. The result is nonuniform even if finding the order is expensive. If the reported external lower bounds are correct, such a description cannot hold for all sufficiently large HC instances or permanent instances outside characteristic two. At least one premise must fail. This is a restricted-model consequence, not a bound on arbitrary bit algorithms, lookup machines or the actual finite benchmark size. No claim of polynomial complexity for arbitrary SAT follows.

Boolean boundary: an arithmetic expression that agrees on the Boolean cube can differ as a polynomial. Over F_2, x^2+x evaluates to zero at 0 and 1 but is nonzero formally. Thus Boolean equivalence modulo (x_i^2-x_i) is a weaker contract than formal polynomial identity. Exact integer counts are also distinct from counts reduced modulo a prime. In characteristic two permanent equals determinant as a formal polynomial; Hamiltonian cycle remains the relevant claimed hard family. In characteristic three the permanent lower-bound claim still applies. A ternary address alone does not change the field or model.

## Preregister proposed acceptance target (not executed here)

1. Separate formal weighted-polynomial evaluation, Boolean decision, and integer model count arms. Symbolic identities must be certified by exact algebraic reasoning; agreement on sampled values or Boolean inputs is insufficient. Compare permanent and determinant on exact integer matrices and over F_2 and F_3, and Hamiltonian cycle on the same graph families.
2. Start with path, tree, grid and complete networks. Include weighted edge-matching tensors with q-valued wires: across any partition, their flattening rank is q^(number of crossing wires), since internal wires contribute rank-one factors and every crossing wire contributes an identity matrix. Rank is invariant under invertible local basis changes across that partition, but not under arbitrary global address permutations. A coordinate change may lower a particular rank only if its own complexity and induced observable are accounted for.
3. Measure source recognition, transformations, symbolically represented circuit gates, message entries and bit sizes, witness reconstruction and independent verification. Compare with conventional optimized variable elimination and matching/permanent/Hamiltonian-cycle algorithms where applicable. Keep the decision versus counting benchmarks separate and log width HOLD as HOLD, never UNSAT.
4. Use the arithmetic lower bounds as a consistency constraint rather than evidence that P=NP or P!=NP. Study whether Boolean-specific transformations exploit the weaker equivalence contract.
