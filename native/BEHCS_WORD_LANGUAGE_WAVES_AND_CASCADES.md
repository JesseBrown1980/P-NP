## New executable scoped acceptance

`native/src/bin/language_cascade.rs` consumes the **original named
words** from the second-cascade dimensions, distributed across
twenty independent hosted GitHub workers by global point index
modulo 20. The index uniquely identifies every one of 93,312
execution records. Each event carries its named six-dimensional key,
is Q-PRISM-transcoded 256→1024→256 with exact byte recovery, and
is also projected onto a search bucket `(verb,target,wave)`.
There are exactly 432 search buckets, each with 216 contributions
when all leaf shards are combined. The projected accumulator
is intentionally non-injective; retaining the original word
dimensions enables exact reconstruction.

Each leaf returns a canonical word-source checksum, per-bucket
counts, exact word/PRISM tally and source provenance. The fan-in
regenerates each leaf independently and checks the 93,312 unique
events, 432 bucket totals and new source-bound root. The next wave
takes the prior worker's artifact and checks exact source-word
restoration against pinned words and source digest. The final
verification requires twenty reverse receipts, with mutations,
missing leaves and incorrect roots rejected.

The paired Chariot Rust workflow already has independent passing
evidence for its 540-cell signed Brown Ledger forward/reverse
round-trip. Word-cascade results must pass their **own hosted
receipt gate**; the Chariot seal is never altered.

Unicode glyphs** in the canonical IX-700 source order. It ports the
original `codex-bridge.js` rule: compute SHA-256 over the complete
typed word, use the first eight digest bytes, and display those
byte values as glyphs in low-base-256 digit order. The inverse
recovers the eight-byte digest prefix, and the source word is
