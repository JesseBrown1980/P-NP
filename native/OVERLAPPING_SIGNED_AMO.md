## Exact theorem

After exact affine parity elimination, each residual two-singleton-literal clause (not A or not B) certifies an edge between signed literals A and B. Greedily extend an uncovered edge only with vertices adjacent to every existing class vertex and on distinct underlying variables. Every discovered class is complete in the original signed graph. The union of all discovered class edges and remaining individual edges must exactly equal the source edge set; all other clauses survive unchanged. Shared vertices and opposite signs across classes are permitted. This certificate does not require minimum clique cover. Missing edges are never inferred.

For a complete class l_1,...,l_k, let s_1=l_1, and for j=2,...,k-1 impose s_j = s_(j-1) OR l_j and forbid s_(j-1) AND l_j. For the last literal just forbid s_(k-1) AND l_k. Each intermediate equivalence uses three clauses, and the exclusion uses one. Each satisfying source assignment uniquely determines all new counter variables. Conversely, each satisfying extension enforces at most one active literal per class. Independent new counters per class preserve this bijection for overlapping classes, even with mixed signs. Thus ordinary model counts including the new counters are exactly the original projected counts. This is a standard sequential AMO encoding strengthened by defining equivalences for unique extension, combined with certified signed clique coverage and affine decoding. It is not a claim of novel general SAT preprocessing. The encoding uses k-2 fresh bits and 4(k-2)+1 clauses per class. It need not lower overall width for arbitrary interactions.
